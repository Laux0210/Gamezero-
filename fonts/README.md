# Fontes locais

- `inter-latin.woff2`: Inter, pesos 400–700, Google Fonts.
- `instrument-serif-regular.woff2`: Instrument Serif regular, Google Fonts.
- `instrument-serif-italic.woff2`: Instrument Serif italic, Google Fonts.

As fontes são servidas localmente para evitar mudança de layout e falhas de carregamento por bloqueio do provedor externo.
